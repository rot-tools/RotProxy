# ROT PROXY identity

The visual reference was the owner's `rot-tools` GitHub avatar and Rot Client palette: near-black surfaces, sharp white ROT lettering, a crimson diagonal accent and a violet square.

The final project icon is `src/main/resources/assets/rotproxy/icon.png`. It was generated using the built-in image generation tool, not an API key or CLI fallback. The settings screen uses the same image and the palette in `RotProxyTheme`.

Generation prompt:

> Create a square production Minecraft mod icon for RotProxy in the exact brand family of the supplied rot-tools GitHub avatar (style reference). Retain the distinctive sharp italic angular white ROT wordmark, black near-flat background, thin diagonal vivid crimson red slash from bottom left to top right behind lettering, tiny violet square/dot at lower right of ROT. Adapt to the proxy mod by adding the exact word PROXY below ROT in widely spaced, crisp compact white uppercase sans-serif. ROT should dominate; PROXY must remain legible. Composition centered, clean flat high-contrast digital logo, generous safe margin, no mockup, no photographic textures, no extra symbols, no other text, square 1024x1024. Deliver a crisp PNG suitable for use at small sizes.
